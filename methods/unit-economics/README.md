# Unit Economics

Что: расчёт экономики единицы (CAC, LTV, Margin, Payback period).

Зачем: понять, рентабельна ли кампания в базовых экономических показателях.

Входные данные: транзакции, расходы по каналам, средний чек, retention rates.

Шаблон вывода: таблица расчётов и рекомендации (ускорять/приостанавливать канал, поднимать LTV и т.д.).
