# McKinsey 7S

Что: модель согласования 7 элементов организации: Strategy, Structure, Systems, Shared Values, Skills, Style, Staff.

Зачем: показать, насколько кампания и организационные процессы согласованы и где нужны изменения.

Шаблон вывода: краткая диагностика по каждому из 7S и рекомендации по настройке.
