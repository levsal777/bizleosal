# Porter\'s Five Forces

Что: анализ конкурентных сил: угроза новых входящих, сила поставщиков, сила покупателей, угроза заменителей, конкурентное соперничество.

Зачем: понять конкурентное давление и возможности для улучшения позиции кампании/продукта.

Шаблон вывода: по каждой силе — оценка (низкая/средняя/высокая) и рекомендации.
