# SWOT

Что: SWOT — инструмент для быстрого обзора сильных и слабых сторон кампании, а также внешних возможностей и угроз.

Зачем: помогает менеджеру понять, какие внутренние ресурсы можно использовать и какие внешние риски требуют внимания.

Входные данные:
- KPI кампании (CTR, CR, CAC, LTV)
- внутренние ресурсы (бюджет, команда, каналы)
- внешние факторы (рыночные тренды, конкуренты)

Шаблон вывода:
- Список 5 сильных сторон
- Список 5 слабых сторон
- 3 ключевые возможности
- 3 основных угрозы
- Рекомендации (3 пункта)
