# Перечень стратегических моделей для анализа кампании

В проекте перечислены и реализованы шаблоны для 8 стратегических методик, применимых к анализу маркетинговой/продуктовой кампании.

1. SWOT — Strengths, Weaknesses, Opportunities, Threats
2. PESTEL — Political, Economic, Social, Technological, Environmental, Legal
3. Porter\'s Five Forces — конкурентный анализ
4. McKinsey 7S — согласование стратегии, структуры, систем и др.
5. Unit Economics — оценка экономической эффективности единицы (LTV/CAC и пр.)
6. AARRR — Acquisition, Activation, Retention, Referral, Revenue (pirate metrics)
7. RFM — Recency, Frequency, Monetary (сегментация клиентов)
8. BCG Matrix — позиционирование продуктов/кампаний по росту/доле рынка

Для каждой методики в папке methods/<slug>/ будет:
- README.md с объяснением "что это, зачем, входные данные"
- template.ipynb (или script) с примером анализа
- sample_data.csv — пример данных (анонимный)
