# AARRR (Pirate metrics)

Что: метрики воронки: Acquisition, Activation, Retention, Referral, Revenue.

Зачем: диагностировать, на каком этапе воронки теряются пользователи и где инвестировать усилия.

Шаблон вывода: воронка с % конверсий между шагами, сегментация по каналам и рекомендации для оптимизации.
