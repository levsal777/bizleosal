# PESTEL

Что: PESTEL анализирует внешние факторы — политические, экономические, социальные, технологические, экологические и правовые.

Зачем: выявить макро‑тренды и риски, которые влияют на результаты кампании и стратегические решения.

Входные данные:
- новости/политические объявления
- экономические индикаторы (курс, инфляция)
- демографические тренды

Шаблон вывода: краткий список факторов по категориям и рекомендации для mitigation/использования.
