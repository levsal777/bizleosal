# Bizleosal

## Описание проекта

`Bizleosal` — минимальный статический веб-проект (HTML + CSS), который сейчас развивается от базовой страницы к полноценному MVP.

Текущий фокус:
- стабилизация базовой структуры;
- улучшение контента и UX;
- внедрение инженерных практик качества.

## Как запустить локально

Проект не требует сборки и внешних зависимостей.

### Вариант 1: открыть файл напрямую
1. Перейдите в папку проекта.
2. Откройте `index.html` в браузере.

### Вариант 2: через локальный HTTP-сервер (рекомендуется)
Из корня проекта выполните:

```bash
python -m http.server 8000
```

После запуска откройте в браузере:

- `http://localhost:8000`

## Структура проекта

```text
.
├── index.html                    # Главная страница
├── css/
│   └── main.css                  # Базовые стили
├── PROJECT_READINESS_REPORT.md   # Отчёт по аудиту готовности
└── DEVELOPMENT_GUIDE.md          # Подробный план дальнейшей разработки
```

## План развития (кратко)

1. Расширить `index.html` до семантической структуры (header/main/section/footer).
2. Улучшить стили и адаптивность в `css/main.css`.
3. Внедрить автоматические проверки (линтеры/валидация/CI).
4. Поддерживать актуальность документации (`README`, отчёты аудита, changelog).

## Соглашения по проекту

- **Кодировка:** UTF-8 для всех текстовых файлов.
- **Отступы:** 4 пробела (единый стандарт для HTML/CSS/Markdown).
- **Именование файлов:** `kebab-case` для новых файлов и директорий (например: `project-readiness-report.md`).

## Проверки качества

В проект подключены:
- `HTMLHint` для проверки HTML;
- `Stylelint` для проверки CSS;
- `Prettier` для единообразного форматирования.

Команды:

```bash
npm install
npm run lint
npm run format:check
```

CI workflow находится в `.github/workflows/ci.yml` и запускает проверки на каждый `push` и `pull_request`.

## Процесс разработки

- История изменений ведётся в `CHANGELOG.md`.

## Как посмотреть визуально страницу

### Способ 1 (самый быстрый)
1. Откройте файл `index.html` двойным кликом в браузере.
2. Страница откроется сразу как статический HTML.

### Способ 2 (рекомендуется)
1. Откройте терминал в корне проекта.
2. Запустите локальный сервер:

```bash
python -m http.server 8000
```

3. Перейдите в браузере по адресу:

- `http://localhost:8000`

### Что проверить визуально
- Видны блоки: `header`, `Преимущества`, `Как это работает`, `FAQ`, `footer`.
- Текст читаем и не слипается.
- На мобильной ширине (например, 480px) отступы и размеры текста становятся компактнее.
